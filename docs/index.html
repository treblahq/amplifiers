How to use an amplifier

No installation. No dependencies. Just text instructions.

Pick an amplifier

Browse the list above and find the capability that matches your task.

Open the SKILL.md

Each amplifier has a single SKILL.md file with the full instruction set.

Paste into your agent

Copy the content into your agent's system prompt, custom instructions, or AGENTS.md.

Combine freely

Multiple amplifiers can live in the same prompt — they're designed to compose.
