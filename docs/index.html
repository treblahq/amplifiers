Amplifiers

Instruction blocks you paste into any AI agent to make it better at one specific thing. No packages. No config. Just a SKILL.md and a system prompt.

Open Source MIT License 6 amplifiers
💡 No installation. Every amplifier is plain text. Paste the contents of any SKILL.md into your agent's system prompt, AGENTS.md, or CLAUDE.md.

Each one does one thing. They stack well in the same prompt.

Quick start #

No packages. No CLI. Pick one, paste it, done.

  1. 01

    Pick an amplifier

    Find the one that matches what your agent needs to be better at.

  2. 02

    Open the SKILL.md

    One file. The full instruction set is in there.

  3. 03

    Paste into your agent

    Into the system prompt, AGENTS.md, or CLAUDE.md.

  4. 04

    Stack as many as you need

    Multiple amplifiers in the same prompt work fine. They are built to coexist.

AGENTS.md CLAUDE.md 
# My Agent Instructions

## Writing style
# ↓ paste contents of humanize-writing/SKILL.md
# [Humanize Writing skill content goes here]

## Backend architecture
# ↓ paste contents of django-drf/SKILL.md
# [Django + DRF skill content goes here]
ℹ️ The amplifiers are plain text. If your model takes a system prompt, they work. Claude, GPT, Gemini, local models.
