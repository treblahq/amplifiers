Amplifiers

Reusable instruction blocks for AI agents. Each amplifier handles one job well. No packages, no setup, just a SKILL.md file you can drop into your system prompt.

Open Source MIT License 6 amplifiers
💡 No install step. Amplifiers are plain text. Copy the contents of SKILL.md into your agent instructions, AGENTS.md, or CLAUDE.md and run.

Available amplifiers #

Each one solves a specific problem. Use one or combine several.

Quick start #

No package install, no CLI, no setup flow.

  1. 01

    Pick an amplifier

    Start with the bottleneck your agent has right now.

  2. 02

    Open the SKILL.md

    Every module is self-contained in one file.

  3. 03

    Paste into your agent

    Paste into your system prompt, AGENTS.md, or CLAUDE.md.

  4. 04

    Stack as many as you need

    Combine modules when your workflow spans writing, backend, and frontend concerns.

AGENTS.md CLAUDE.md 
# My Agent Instructions

## Writing style
# ↓ paste contents of humanize-writing/SKILL.md
# [Humanize Writing skill content goes here]

# [Django + DRF skill content goes here]
