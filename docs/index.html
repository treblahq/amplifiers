Amplifiers

Instruction blocks you paste into any AI agent to make it better at one specific thing. No packages. No config. Just a SKILL.md and a system prompt.

Open Source MIT License 6 amplifiers
💡 No installation. Every amplifier is plain text. Paste the contents of any SKILL.md into your agent's system prompt, AGENTS.md, or CLAUDE.md and it works on any model — Claude, GPT, Gemini, anything that takes a system prompt.

Available amplifiers #

Each one does one thing. They stack — multiple amplifiers in the same prompt work fine.

✍️
Humanize Writing humanize-writing

Strips 24 documented AI writing patterns and puts voice back in. Significance inflation, vague attributions, em dash overuse, sycophantic tone — each one caught and fixed. Based on Wikipedia's Signs of AI Writing guide.

writing editing content ai-patterns

Prompt Engineering prompt-engineering

Takes a rough idea and turns it into a prompt that works. Covers image, video, audio, and text generation — Gemini, Suno, Runway, and general LLMs. Knows what each platform responds to.

Knowledge Writing knowledge-writing

Maps a codebase and writes documentation by topic — one file per concern, no sprawl. Outputs clean markdown in snake_case, indexed through a README. Factual only, no filler.

Quick start #

No packages. No CLI. Pick one, paste it, done.

01

Pick an amplifier

Find the one that matches what your agent needs to be better at.

02

Open the SKILL.md

One file. The full instruction set is in there.

03

Paste into your agent

Into the system prompt, AGENTS.md, or CLAUDE.md. Works on any model.

04

Stack as many as you need

Multiple amplifiers in the same prompt work fine. They're built to coexist.

AGENTS.md CLAUDE.md 
# My Agent Instructions

## Writing style
