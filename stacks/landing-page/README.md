# Landing page

> Compose copy, design, semantic structure, writing polish, and prompt support for marketing pages.

## Uses

- [sales-copywriter](../../skills/sales-copywriter/SKILL.md)
- [designer](../../skills/designer/SKILL.md)
- [html-architect](../../skills/html-architect/SKILL.md)
- [humanizer](../../skills/humanizer/SKILL.md)
- [prompt-engineer](../../skills/prompt-engineer/SKILL.md)

## Use when

- Building or rewriting a landing page outside a React-specific delivery
- Turning an offer brief into a conversion-oriented page
- Combining strategy, page structure, and final copy refinement

## Suggested order

1. Use `sales-copywriter` for the persuasive spine
2. Use `designer` for hierarchy, pacing, and emphasis
3. Use `html-architect` for semantic structure and accessibility
4. Use `humanizer` to remove robotic phrasing
5. Use `prompt-engineer` when the campaign also needs supporting creative assets

## Output standard

- clear page angle and section structure
- stronger visual hierarchy
- semantic implementation direction
- tighter, more human copy
