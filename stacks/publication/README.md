# Publication

> Compose documentation structure, prompt distillation, and writing cleanup to publish reusable artifacts from deeper source material.

## Uses

- [knowledge-writer](../../skills/knowledge-writer/SKILL.md)
- [prompt-engineer](../../skills/prompt-engineer/SKILL.md)
- [humanizer](../../skills/humanizer/SKILL.md)

## Use when

- Publishing a new skill from a source package
- Splitting a deep source into reusable runtime artifacts
- Improving how the library explains and distributes its own building blocks

## Suggested order

1. Use `knowledge-writer` to define artifact boundaries and structure
2. Use `prompt-engineer` to tighten runtime-facing instructions
3. Use `humanizer` to keep the docs readable and direct

## Output standard

- clearer artifact boundaries
- reusable published skills
- cleaner stack documentation
- better source-to-runtime mapping
