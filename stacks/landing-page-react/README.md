# Landing page React

> Compose conversion design, sales copy, writing polish, and React architecture for landing pages built in a React stack.

## Uses

- [designer](../../skills/designer/SKILL.md)
- [sales-copywriter](../../skills/sales-copywriter/SKILL.md)
- [humanizer](../../skills/humanizer/SKILL.md)
- [react-architect](../../skills/react-architect/SKILL.md)

## Use when

- Building a landing page directly in a React application
- Reworking a product-marketing page that needs both conversion and frontend structure
- Shipping a page where layout, copy, and component architecture need to evolve together

## Suggested order

1. Use `sales-copywriter` to define the angle and section logic
2. Use `designer` to define hierarchy and conversion pacing
3. Use `react-architect` to define the component structure and implementation boundaries
4. Use `humanizer` to polish the final page copy and UI text

## Output standard

- clear marketing structure
- implementation-ready React breakdown
- improved copy and CTA language
- stronger alignment between conversion logic and frontend execution
