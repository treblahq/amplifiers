# Code of Conduct

## Our commitment

We want this project to be a respectful, inclusive, and safe space for everyone.

## Expected behavior

- Be respectful and constructive
- Assume good intent, ask for clarification when needed
- Give actionable feedback focused on the work
- Welcome different backgrounds and perspectives

## Unacceptable behavior

- Harassment, discrimination, or hate speech
- Personal attacks, insults, or intimidation
- Publishing private information without permission
- Repeated disruptive behavior after moderation requests

## Scope

This Code of Conduct applies to project spaces, including:

- GitHub issues and pull requests
- Discussions and comments
- Any public communication representing this project

## Enforcement

Project maintainers are responsible for enforcing this Code of Conduct and may remove, edit, or reject content that violates it.

Possible actions include:

- Warning
- Temporary restriction
- Permanent ban from project interaction

## Reporting

If you experience or witness unacceptable behavior, report it to maintainers via GitHub (issue or direct contact through the repository owners).

All reports will be reviewed and handled as promptly and fairly as possible.
