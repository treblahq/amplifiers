# Frontend feature delivery

> Compose product design, React architecture, writing polish, and documentation into one frontend workflow.

This superpower is for shipping UI work that needs more than code alone. It
combines interface structure, React implementation boundaries, polished
microcopy, and minimal documentation updates.

## Composes

- [react-ecosystem](../../amplifiers/react-ecosystem/SKILL.md)
- [product-design](../../amplifiers/product-design/SKILL.md)
- [humanize-writing](../../amplifiers/humanize-writing/SKILL.md)
- [knowledge-writing](../../amplifiers/knowledge-writing/SKILL.md)

## Use when

- Shipping a new frontend feature from brief to implementation
- Refactoring a screen that is both visually weak and structurally messy
- Improving an existing flow that needs better hierarchy, microcopy, and docs

## Workflow

1. Clarify the product goal, user action, and acceptance criteria
2. Define the layout logic, hierarchy, and primary interaction flow
3. Implement the feature with clear React boundaries and reusable structure
4. Polish UI text, labels, and empty states so the interface reads naturally
5. Update the relevant documentation when the feature changes system behavior

## Output standard

- A clear screen or flow structure
- React implementation guidance or code-ready instructions
- Polished microcopy for key UI states
- Notes for responsiveness and implementation constraints
- A doc update path when the feature changes the product surface
