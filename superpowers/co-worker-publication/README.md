# Co-worker publication

> Distill upstream co-worker material into publishable amplifiers, superpowers, and agents.

This superpower is for turning broad source material into tighter open-source
artifacts. It combines documentation structure, prompt distillation, and prose
cleanup so a deep co-worker package can become one or more reusable published
modules.

## Composes

- [knowledge-writing](../../amplifiers/knowledge-writing/SKILL.md)
- [prompt-engineering](../../amplifiers/prompt-engineering/SKILL.md)
- [humanize-writing](../../amplifiers/humanize-writing/SKILL.md)

## Use when

- Turning a co-worker into an amplifier
- Publishing a repeatable workflow as a superpower
- Assembling a stable collaborator as an agent
- Creating the docs that explain how source material maps to published artifacts

## Workflow

1. Inspect the co-worker package and identify the strongest reusable units
2. Decide whether the material should become an amplifier, superpower, agent, or a subset of those
3. Distill runtime-ready instructions into `SKILL.md` where appropriate
4. Write human-facing `README.md` files that explain scope, composition, and usage
5. Update repository indexes and source maps so the publication model stays visible

## Output standard

- Clear artifact boundaries
- Runtime-ready skill files when the unit is reusable
- Human-facing READMEs for composition and navigation
- Updated repository documentation that explains the new publication path

## Example tasks

- Publish `product-design` from `co-workers/designer/`
- Publish `laravel-api` from `co-workers/software-architect/laravel/`
- Create superpowers and agents from multiple published amplifiers
