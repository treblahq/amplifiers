# Superpowers

> Composition-first workflows built from multiple amplifiers.

Superpowers combine several amplifiers into a reusable delivery pattern. Use
them when one isolated skill is not enough and the work benefits from a
repeatable sequence across design, implementation, writing, or review.

## Available superpowers

- `frontend-feature-delivery/`
- `landing-page-delivery/`
- `repository-documentation-delivery/`
- `co-worker-publication/`
