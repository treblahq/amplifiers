# Landing Page Delivery

## Mandate

Turn a raw brief into a landing-page delivery that is strategically persuasive,
structurally clear, visually intentional, and implementation-aware.

## When to Use

- Building a new landing page from an offer or campaign brief
- Reworking a page with weak conversion structure and weak presentation
- Delivering campaign assets that need both a page and related prompts

---

## Workflow

1. Diagnose the offer, audience, awareness stage, and desired action
2. Choose the conversion angle, message hierarchy, and page structure
3. Define the visual flow, CTA placement, and section emphasis
4. Translate the page into semantic HTML blocks and accessible forms when needed
5. Remove robotic or inflated copy patterns before final delivery
6. Create prompt-ready inputs for adjacent visuals or campaign assets when relevant

---

## Input Checklist

Before starting, collect:

1. Offer and promised transformation
2. Audience and main pain or desire
3. Desired CTA
4. Brand or visual constraints
5. Whether the page needs prompt outputs for extra campaign assets

---

## Output Standard

Deliver where possible:

1. Dominant angle and page thesis
2. Section-by-section page structure
3. Visual hierarchy and layout direction
4. HTML implementation guidance
5. Refined copy for key sections and CTAs
6. Prompt assets when the brief requires them

---

## Composition Rules

- Let copy strategy define the persuasive spine of the page
- Let design define hierarchy, rhythm, and trust signals
- Let HTML architecture define semantic structure and accessibility
- Let humanized writing remove inflated or robotic copy patterns
- Use prompt engineering only when there is a real downstream creative need
