# Landing page delivery

> Combine offer strategy, copy, design, semantic implementation, and prompt generation into one launch workflow.

This superpower turns a raw offer or campaign brief into a landing-page delivery
system. It joins persuasive structure, visual hierarchy, semantic HTML,
humanized copy, and optional prompt packages for adjacent creative work.

## Use when

- Turning an offer brief into a landing page strategy
- Reworking a page that has weak copy, hierarchy, and structure at the same time
- Producing a page plus adjacent prompt assets for ads, visuals, or creative tools

## Workflow

1. Diagnose the offer, audience, awareness stage, and CTA
2. Define the page narrative and conversion structure
3. Design hierarchy, section pacing, and CTA emphasis
4. Translate the page into semantic HTML structure and reusable blocks
5. Polish the copy so it sounds clear and human
6. Generate prompt assets when the campaign needs supporting creative output

## Output standard

- Page strategy and section logic
- Conversion-oriented copy direction
- Design hierarchy and layout guidance
- Semantic HTML implementation guidance
- Prompt packages for related creative work when relevant
