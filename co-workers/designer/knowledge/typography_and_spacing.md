# Typography And Spacing

> **Objective:** Use type and space as the main structural tools of high-quality design.

Most strong interface design is built on typography and spacing before color, illustration, or decoration.

## Typography Principles

Use typography as a system, not as a last-mile styling choice.

Key controls:

- type scale
- font weight
- contrast between headline and body
- line height
- paragraph rhythm
- text alignment

## Spacing Principles

Spacing defines clarity, breathing room, and perceived quality.

Use spacing to:

- separate unrelated elements
- group related content
- establish reading rhythm
- reduce cognitive load

## Practical Rules

- Keep heading sizes purposeful and clearly differentiated
- Use line height to improve readability, not to fill space
- Avoid overly dense text blocks
- Build consistent spacing intervals across the screen
- Let whitespace create order instead of filling every area

## Design Quality Signal

Weak typography and weak spacing make even good ideas look average.

Strong typography and consistent spacing make simple interfaces feel professional and premium.
