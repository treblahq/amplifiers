# Co-workers

> Source material used to distill published amplifiers, superpowers, and agents.

This folder contains broader role instructions, knowledge bases, experiments,
and reference material. Treat it as the authoring layer of the repository.

## Publishing rule

- Publish an amplifier when one reusable runtime capability is clear and stable.
- Publish a superpower when multiple amplifiers form a repeatable workflow.
- Publish an agent when that workflow becomes an opinionated collaborator.
- Do not force a one-to-one mapping from every co-worker to every artifact type.
