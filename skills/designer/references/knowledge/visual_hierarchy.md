# Visual Hierarchy

> **Objective:** Make the most important information and action understandable within the first second.

Strong hierarchy tells the user three things immediately:

1. What matters most
2. What to do
3. Where to look next

## Hierarchy Tools

Use these levers intentionally:

- size
- contrast
- spacing
- typography weight
- color emphasis
- grouping and separation

## Good vs Bad Hierarchy

Bad hierarchy happens when every element competes for attention.

Good hierarchy happens when only the critical message and action stand out, while the rest supports the flow.

## Practical Rules

- One dominant message per section
- One obvious primary action per step
- Secondary information must look secondary
- Repetition of emphasis weakens emphasis
- Visual noise reduces clarity and trust

## Review Questions

- Can the user identify the main message instantly?
- Is the CTA visually and contextually clear?
- Does the layout guide the eye in a deliberate sequence?
- Are there elements drawing attention without earning it?
