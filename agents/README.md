# Agents

> Opinionated collaborators assembled from amplifiers and superpowers.

Agents package a reusable working style around a set of amplifiers and
superpowers. They are the most assembled layer in the repository and should be
created only when the composition is stable enough to describe as a collaborator
instead of a loose stack of skills.

## Available agents

- `frontend-product-builder/`
- `conversion-launch-builder/`
- `open-source-publisher/`
