# Knowledge

> Internal markdown documentation for the Amplifiers repository itself.

Use this folder for architecture notes, catalog pages, and testing guidance.

Do not use `docs/` for this material. `docs/` is reserved for the published HTML
site.

Amplifiers itself is written around the
[Agent Skills](https://agentskills.io/) package model, while `knowledge/`
stores maintainership documentation about how this repository applies that
standard.
