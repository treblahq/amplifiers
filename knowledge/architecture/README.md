# Architecture

> Documents the active repository structure and its authoring rules.

Current direction:

- `skills/` for directly attachable runtime specialists and modifiers
- `stacks/` for recurring combinations
- `references/` inside each skill for deep supporting material
- `knowledge/` for internal markdown documentation
- `docs/` for the published HTML site

External baseline:

- [Agent Skills](https://agentskills.io/)
- [OpenAI Codex skills](https://developers.openai.com/codex/skills)
- [Anthropic Claude skill guide](https://resources.anthropic.com/hubfs/The-Complete-Guide-to-Building-Skill-for-Claude.pdf)
